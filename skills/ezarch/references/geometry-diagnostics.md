# 所选几何的观测与定位

`ezarch.walls` 提供可独立调用的只读几何检查，`ezarch.diagnostics` 提供定位范围计算。用途是取得测量与可核查的疑点；不生成设计、修复对象或判断整图合格。调用哪些能力、如何解释和处理结果，由 AI 根据用户需求、设计意图和其他证据决定。也可使用原生 API、自写算法或其他工具。

另有独立的 [标注占位观测](text-dimensions.md#标注占位观测) 和 [局部截面/点连通](spatial-measurement.md#局部截面与连接证据)，无需先运行本页检查。它们复用 location / issue_region，但保留各自的结果与范围；不是统一验收清单。`geometry_location(geometry, *, precision)` 可为其他非空有限二维观测生成坐标包围盒及代表点，precision 由调用者说明定位依据；不凭包围盒创建缺陷判断。含 Shapely 几何的结果按需转换后再序列化，本页 walls 返回字典的 JSON 特性不自动扩展到其他接口。

## 输入与入口

`inspect_geometry(geometries, *, checks, unit_mm, short_edge_mm=None, reversal_deviation_deg=None, min_edge_mm=0, expected_ids=None)` 接受对象 ID 到 Shapely 几何的映射。ID 为非空字符串；支持 Polygon、MultiPolygon、LineString、LinearRing、MultiLineString 的有限二维直边坐标。输入不必代表墙，也不要求项目按这套映射组织。GeometryCollection、点、空几何、非有限坐标及 Z/M 几何会返回未检查原因。

- `checks` 显式选择下表中的名称，没有默认全检或固定组合。未知名称、缺少必要参数等调用错误会报错，不产生无发现结论。
- `unit_mm` 是每输入单位对应的 mm，必须显式提供；测量长度按 mm，定位坐标保留输入坐标。坐标范围与单位共同超出有限数值表示时返回未检查。
- `short_edge_mm` 是调用者选取的长度阈值；`reversal_deviation_deg` 是与精确反向的允许角差，范围为 0 ≤ 值 < 90°。它们不是制图标准或普遍设计限值。
- `min_edge_mm` 只在回折计算中排除相邻边长不大于该值的顶点，默认 0 仅排除零长边；实际排除数和覆盖缺口会返回。它不负责删边或合并近点。
- `expected_ids` 可表达本次预期选中的对象。缺失 ID 会列出；不提供时没有整图完整性的依据。提供了预期 ID 也只能核对该列表，不能推断未列出的内容。

选择来自同一坐标空间、可比较范围的几何。工具不识别楼层、构件类别或设计用途，不自动决定哪些墙应该连接。独立坐标变换可用 [二维坐标计算](coordinate-transforms.md)；是否转换由当前输入决定。

## 已提供的计算

| 名称 | 实际计算与返回 | 解释边界 |
|---|---|---|
| `validity` | Polygon/MultiPolygon 的 GEOS 有效性；LinearRing 按区域解释。无效时返回后端原因及可用位置 | 不是逐一枚举全部缺陷；通常只给首个原因。开放路径不适用。闭合线条作为轮廓是否合法与它是否适合作为区域不同；不会把闭合 LWPOLYLINE 自动认作实体墙 |
| `short_edges` | 外环、内环和路径的每段长度；长度严格小于显式阈值时返回起终点、边号及长度 | 短边是候选；合理的小细部也可能命中。不会删除短边；一次闭合的终点不另算零长边，内部重复点保留 |
| `backtracks` | 相邻非退化边与反向的角差；不大于显式阈值时返回顶点、邻点、两边长度和角差 | 回折是候选；不自动归因于毛刺。退化边附近和开放路径端点没有可用转角；退化排除另有计数 |
| `duplicates` | 相同几何类型的规范化坐标序列精确比较；忽略方向、区域环起点及多部件顺序，返回重复组和全部 ID | 不忽略冗余顶点，不检查近似重复或部分重线；样式、图层和用途不参与比较。重合可能有意，不能直接推导删除；不足两个可比较输入时为未能检查 |

这些计算使用浮点数和当前 GEOS 实现；不 snap、不自动 make_valid，不作隐式精度栅格化。极端坐标量级、非常接近阈值或数值退化处可能影响结果；实际参数和后端信息保留在结果中。修改阈值只改变本次观测，不改变源几何。范围外包括窄缝/错台关系识别、部分重叠、门洞残线、材料/承重判断、空间可达性、规范及视觉表达；这里不是 AI 可用能力的完整清单。

## 原生 DXF 选择适配

`inspect_dxf_entities(entities, **options)` 接收已选择的 ezdxf 实体，options 同上述函数；不读写文件，不自动查询墙图层、展开 INSERT 或把多张图混合检查。函数签名和计算实现见 [walls.py](../src/ezarch/walls.py)。

当前只适配默认 XY 平面、零高程、无厚度的 LINE，以及无 bulge 的 LWPOLYLINE；闭合多段线作为 LinearRing，开放多段线作为路径。测量的是中心路径/边界坐标，不是多段线宽度、线宽或打印后的可见外廓。

HATCH 只适配 normal 填充样式、闭合直边 PolylinePath、恰好一个 external 外环和标明 outermost 的孔洞。不猜测缺少角色标记、多个外环或岛屿的含义；这类输入以及曲线边界明确列为未检查。调用者理解边界关系后，也可通过原生 API 构造独立区域供 `inspect_geometry` 使用。空选择、未知类型和不支持的 OCS/高程不会被转换成检查通过。

返回源 handle、实体类型、图层和布局名；未绑定 handle 的实体使用本次选择顺序 ID。同一次选择不能有重复 ID。对象标识仅用于定位，不带建筑类别推断；图块定义、模型空间和纸空间的坐标含义各异。适配不会查询源文件版本，结果描述的是调用时的对象状态；源几何随后变化时，旧结果不能代表新状态。

## 结果、覆盖与定位

结果是普通可 JSON 序列化的字典，可留在内存中使用；不要求报告或证据档案。无全局 passed、整体评分或自动修复建议。

- `scope`：输入与预期 ID、缺失项、单位、已选/未选检查，以及输入之外完整性未知的说明。
- `inputs`：每个输入的类型、可用坐标范围、未能读取的原因；DXF 适配附带来源信息。
- `checks`：每项分别给出参数、已检查对象、未检查对象及原因、元素/比较计数和发现。`coverage` 的 complete/partial/none 仅表示本次所选输入的适用覆盖；不是设计完成度。
- `observation` 的 findings/none_found/not_assessed 分别表示有观测、已检查部分未发现、没有可检查内容。partial 与 none_found 可以同时存在，不能忽略未检查列表。
- `findings`：`evidence=representation_invalid` 指当前区域表示被判无效；`candidate` 是短边、回折或重复等需要结合上下文理解的疑点。objects 带对象、部件、环和边/顶点索引；索引从 0 开始，外环名为 exterior，孔洞从 0 编号。未能精确归属的有效性问题只定位到原对象。
- `location`：原坐标中的点和包围盒、定位精度。backend_point 是后端返回的位置，object_bounds 仅定位到对象范围；不是所有有效性原因都能给出精确点。

程序化结果提供特定输入与检查项目的证据。“未发现”仅适用于已检查范围；AI 可结合原始资料、设计意图和其他证据解释、补充或推翻候选判断。选用更多计算、局部看图或其他方法取决于任务，不构成固定复核阶段。

`ezarch.diagnostics.issue_region(finding, *, padding)` 将发现的包围盒向外扩展，padding 为正的输入坐标长度，返回 `(xmin, ymin, xmax, ymax)`。它不绘图、不修改发现，粗定位仍然是粗定位。可接到已有 `ezarch.cad.plot(doc, output, layout_name=..., region=...)` 的 region 或其他查看器；按 [资料查询](file-understanding.md) 找源对象。cad.plot 当前支持模型/纸空间布局，图块定义坐标不能直接当模型空间坐标使用。详见 [diagnostics.py](../src/ezarch/diagnostics.py)。

## 来源与验证边界

区域有效性、边长及相邻方向计算提炼自真实任务的墙体审计；精确重复比较来自重复填充核对。原项目的删点修复、固定阈值、墙厚、图层名称、坐标、计数要求和制图顺序未带入接口。参数化、范围返回和原生适配是新增实现，历史脚本成功运行不等于这些接口已被历史任务验证。

维护测试覆盖单位/方向变化、孔洞与部件定位、临界阈值、合理细部、退化和未知输入、只读性；实际历史文件的复核记录在库外。检查能力不因此覆盖历史任务里全部问题，也不保证 AI 永远不会误读结果。
