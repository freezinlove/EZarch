# 视觉理解、图面判断与继续修改

视觉可以帮助理解参考、推敲空间与形体、比较设计选择、发现问题以及指导修改，具体用途由当前任务决定。以下提示提供观察和判断的方法，按需要取用。

观察对象应是所讨论版本的实际图纸或模型。应从完整 CAD、模型或矢量文件生成视图；只抽取 LINE、多段线或文字会遗漏填充、圆弧、图块、字体和可见性。坐标网格或调试标记可以辅助定位，但不能代表图纸的真实阅读效果。

## 视图怎样帮助理解与推敲

整体视图帮助理解空间组织、形体与场地的关系、主要尺度和信息层次。局部视图用于看清连接、开口、朝向和标注，保留足够周边关系才看得出其作用；平面看不清的高差、遮挡或构造关系，可以借助剖面、模型视角或实际渲染。

看空间时，可沿着实际进入和使用方式理解图面：边界围出了什么，开口通向哪里，设施朝向和使用位置是否相称，剩余空间承担什么作用。功能标签、几何不相交和面积数字都不能替代对这些关系的理解。具体应看什么取决于设计与当前疑问。

看表达时，把图纸放到拟使用的阅读尺度：线的主次是否让对象可辨，文字是否与所指内容对应，颜色和填充是否遮住重要信息。这些观察角度可以帮助形成新的设计判断，也可以用于比较不同表达的取舍。

## 主动发现图面问题

核对本次修改是否生效，与审视当前成果是否有问题，是两种不同的观察目的。制作与修改时，主动留意尚未被指出的异常，不等用户圈出位置才关注。关注范围由任务要求和实际图面展开，不能只围绕刚写的代码、预期改动或已有检查项；也留意尚未认真观察的区域及其与整体的关系。发现或修好几处问题，不代表其他部分已经得到检查。

从图面自行提出值得核实的疑问：哪里与其空间作用、相邻关系、构造表达或阅读方式不相称？把疑点落实为具体位置、可见现象和怀疑的理由，有助于选择下一次观察或修改。所关注的对象与关系应随图纸变化，不以预设问题清单代替观察，也不为凑数量寻找错误。

取得能辨认所讨论关系的视图。整图缩得太小会掩盖线条与连接问题，孤立裁切又会丢失周边关系；可按疑问放大、裁切、转正、临时高亮或切换视角，同时保持局部与整体的对应。局部放大不能代替整体尺度与构图判断，反复打开同一张图也不等于扩大了观察范围。视图的选择、顺序和数量取决于实际需要。

判断以实际图面为依据。生成代码的意图、对象数量或检查通过的日志不能消除图上可见的矛盾；功能标签也不能替代所画空间的作用。视觉疑点需要与已确认的错误区分，尺寸、遮挡、来源或设计依据不清时，可通过原生实体、其他视图、量测或资料补充判断。用户标注提供观察线索，也需要核实，而不是自动认定为错误。

发现问题与修改权限分开：修改范围受限时，仍可以指出相关异常及其影响，不据此擅自扩大设计修改。说明检查结果时，区分已看到的事实、推断和仍看不清的内容；局部核对不能概括为整套成果已无问题。

## 当前视图入口

| 对象 | 操作与坐标 |
|---|---|
| 已有 CAD | `ezarch.cad.plot(doc, output, scale=None, layout_name="Model", handles=None, region=None, dpi=150, *, margin=10, formats=None)`；region 为源坐标的 xmin/ymin/xmax/ymax，默认 PDF/PNG，可选 SVG。完整前端保留支持的曲线、填充和图块；`skipped` 列出前端跳过项，外部参照、代理对象和字体还受实际依赖影响。 |
| 临时隔离或高亮 CAD 对象 | [select_entities / render_view](reference-views-editing.md#选择与临时显示) 接收现有文档，在副本上显示所选对象或覆盖显示属性；支持展开图块实例，源文件不被改写。 |
| 新建 Drawing | `drawing.save(stem, formats=...)` 默认从当前 CAD 实体生成视图，直接改实体或放入组件后再次保存即可更新。细节见 [图纸输出](geometry-drawings.md#保存与继续修改)。 |
| PDF / 图片 | `inspect` / `reference` 的页面或局部预览；PDF 裁切用 pt，图像用 px，详见 [读取](file-understanding.md)。 |
| BLEND / 3DM | [模型视图](geometry-drawings.md#blender-模型剖切与投影)、[场景渲染](rendering.md)、[3DM 预览](file-understanding.md)。模型线框、剖切和渲染各自显示不同信息。 |

## 修改与对照

修改是否生效，看从最新源文件重新生成的图，而不是脚本意图、旧截图或计数日志。前后对照时，一致的区域、比例和视角更容易辨认差异；必要的关联视图随源对象一起更新。既看原来的问题是否在图上消失，也留意改动对周边和整体关系的影响。

现有 DXF 可用 [preview_changes](reference-views-editing.md#选定对象替换与前后对照) 生成同范围、同比例的前后视图，并标色实际实体变化；标色帮助定位，不代表错误判定。

看到异常后回到相应实体、参数或表达修改。取图、高亮、差异显示和量测为 AI 提供观察依据，不产生设计合格结论；这里不设置统一评分、固定轮数或必交验收表。
