# 看清图纸与继续修改

视觉判断的对象是当前实际成果。应从完整 CAD、模型或矢量文件生成视图；只抽取 LINE、多段线或文字会遗漏填充、圆弧、图块、字体和可见性。坐标网格或调试标记可以辅助定位，但不能代表图纸的真实阅读效果。

## 视图怎样帮助判断

整体视图帮助理解空间组织、形体与场地的关系、主要尺度和信息层次。局部视图用于看清连接、开口、朝向和标注，保留足够周边关系才看得出其作用；平面看不清的高差、遮挡或构造关系，可以借助剖面、模型视角或实际渲染。

看空间时，可沿着实际进入和使用方式理解图面：边界围出了什么，开口通向哪里，设施朝向和使用位置是否相称，剩余空间承担什么作用。标签叫“公共空间”、线条没有相交、面积数字足够，都不能替代这些关系。具体应看什么取决于设计与当前疑问。

看表达时，把图纸放到拟使用的阅读尺度：线的主次是否让对象可辨，文字是否与所指内容对应，颜色和填充是否遮住重要信息。局部放大适合查细节，不能据此判断整体尺度与构图。视觉也会遗漏问题；尺寸、被遮挡内容和来源不确定时，原文件、其他视图或直接测量能补充依据。

## 当前视图入口

| 对象 | 操作与坐标 |
|---|---|
| 已有 CAD | `ezarch.cad.plot(doc, output, scale=None, layout_name="Model", handles=None, region=None, dpi=150, *, margin=10, formats=None)`；region 为源坐标的 xmin/ymin/xmax/ymax，默认 PDF/PNG，可选 SVG。完整前端保留支持的曲线、填充和图块；`skipped` 列出前端跳过项，外部参照、代理对象和字体还受实际依赖影响。 |
| 新建 Drawing | `drawing.save(stem, formats=...)` 默认从当前 CAD 实体生成视图，直接改实体或放入组件后再次保存即可更新。细节见 [图纸输出](geometry-drawings.md#保存与继续修改)。 |
| PDF / 图片 | `inspect` / `reference` 的页面或局部预览；PDF 裁切用 pt，图像用 px，详见 [读取](file-understanding.md)。 |
| BLEND / 3DM | [模型视图](geometry-drawings.md#blender-模型剖切与投影)、[场景渲染](rendering.md)、[3DM 预览](file-understanding.md)。模型线框、剖切和渲染各自显示不同信息。 |

修改是否生效，看从最新源文件重新生成的图，而不是脚本意图、旧截图或计数日志。前后对照时，一致的区域、比例和视角更容易辨认差异；必要的关联视图随源对象一起更新。看到异常后回到相应实体、参数或表达修改，视觉判断本身不生成统一评分、固定轮数或验收表。
