# 中国建筑制图表达

按中国建筑技术制图要求工作时，可查阅以下符号、比例和标注规则。是否使用以及采用哪些条款，由任务、地区、图种和设计阶段确定；它们不自动约束概念图、地图、统计图或表现图。制图符合某些条文不等于建筑技术、结构、消防或施工合规。

## 核查依据与范围

来源入口：GB/T 50001—2017《房屋建筑制图统一标准》（第1695号公告，2018-05-01实施），GB/T 50104—2010《建筑制图标准》（第747号公告，2011-03-01实施）；总平还可查《总图制图标准》。任务要求按标准出图时，核实适用版本和项目条件。发布/目录入口：https://www.gongbiaoku.com/mobile/book/nzg18501zaz （出版方工标库）；GB/T 50001—2017参考文本：https://download.hustp.com/d/file/word/2023/01/20230104_212222.pdf （公开镜像，需与正式标准核对）。不在仓库分发整本标准。

以下是已用于助手的局部表达规则和条文定位，不是全文合规清单：

| 表达 | 依据 | 实施/检查 |
|---|---|---|
| 文字/线条不混淆 | 50001 §4.0.10、§5 | 按实际纸面检查碰撞，按字体类型选字高；字母数字不小于2.5mm |
| 比例 | §6 | 模型1:1，纸面定比例，不缩放后保留旧比例标签 |
| 常用剖切符号 | §7.1.4 | 粗位置线6–10mm、垂直方向线4–6mm；检查方向、编号、图纸对应 |
| 索引 | §7.2 | 圆及分隔线，上编号/下图号；助手为普通跨图纸形式，特殊形式自行适配 |
| 引出线 | §7.3 | 说明与对应构件关联，避免交叉，多层做法按构造顺序 |
| 指北针 | §7.4.3 | 普通圆直径24mm、尾宽3mm；与项目北向一致 |
| 定位轴线 | §8 | 点划线、圆径8–10mm；通常横数字纵大写字母，I/O/Z不用 |
| 尺寸 | §11.1–11.3 | 真值、细尺寸线、斜短线；界线离轮廓≥2mm，超线2–3mm；分尺寸靠近图形、总尺寸置于外侧，间距按图面组织 |
| 标高 | §11.8 | 三角尖端对应高度；m、三位小数；零为±0.000，正值不写＋ |

样式参数见 assets/drafting/china-conventions.yml。Drawing 的 style 可覆写 pens_mm、axis_circle_diameter_mm、index_circle_diameter_mm、north_circle_diameter_mm、section_position_length_mm、section_direction_length_mm、excluded_axis_labels，这些参数实际用于生成图元。默认加载的中国制图样式不是所有任务的规定；轴号排除规则也属于该样式，可按所用规则覆盖。线宽分配、默认字体和采用的具体符号尺寸是本库的样式选择；是否满足适用条文仍按本次要求判断。附带字体为开放仿宋风格 TTF，并非微软字体或工程 SHX。字体选择由任务决定；其他字体和符号可直接通过 ezdxf/SVG 或项目适配器使用。

## 技术图可涉及的内容（按阶段选用）

例如平面的定位、功能、开门/楼梯方向、尺寸和标高；立面的主要高度、洞口与材料；剖面的层高、楼地面/屋面层次与空间关系；详图的连接、尺寸及材料说明。它们是查找相关表达的提示，不是每张图都必须包含的清单。局部图、概念图和完整技术图可以有不同内容。

当一套技术图引用相同轴线、图号或标高时，对应关系影响正确性。字高、线宽和比例按实际打印尺寸判断；分析图的箭头和颜色不自动具有工程规范符号的含义。版式与表达手法仍按用户参考和模型判断组织。

## 二维图块

Drawing.furniture 提供普通可编辑 chair/sofa/bed/table/counter/cabinet/shelf/sink/wc/shower/equipment 线条，按真实外廓和旋转生成；这些是表现惯例，不称国家标准家具。特殊家具按参考生成。视图比例控制简化程度，实际使用空间另行校核。

## 使用

`ezarch.drafting.Drawing(bounds, scale, title, number, style=None, font=None)` 独立于三维。bounds 包含注释区（世界mm）；poly/text/axis/dimension/chain/level/north/section_mark/index/leader/furniture 生成同源 DXF/PDF/SVG。pen与文字高度为纸面mm，物体坐标为模型mm。

模型视图可设置 drafting 命令列表，op为以上方法名，其余键为方法参数；drawing_bounds显式预留标注区。所有标注由项目按任务组织，不自动把相同符号撒到每张图。

## 取用图元时的技术区别

门的开向可用叶片线和圆弧表达，窗框可用平行线/块表达；楼梯踏步、平台、方向箭头、剖切折断与上下层投影分别处理，避免把剖切几何自动当成完整建筑符号。填充的边界、孔洞与图面比例影响材料表达。

直接 ezdxf 操作可用 `msp.add_arc(hinge, radius, start_angle, end_angle)`、`doc.blocks.new(name)` 与 `msp.add_blockref(name, insert)`；块的原点、朝向和尺寸在项目内定义。填充用 `msp.add_hatch()` 后为 `hatch.paths` 添加外轮廓和孔洞，`hatch.set_pattern_fill(...)` 的比例和角度按该图控制。它们是工具操作，不声称任一通用门窗/家具图块属于国家标准图样。

建筑面积、净面积、门净宽、结构标高与完成面标高各自有定义；具体尺寸依据和符号含义需对应项目。对当前图纸有影响的核对可直接量测与看图，不需要扩充为全项目规范清单。
