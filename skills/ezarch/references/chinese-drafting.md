# 中国建筑制图表达

制图依据定位与随库绘图参数。适用约定取决于地区、图种与项目要求，库内默认样式不是标准条文。

墙体节点、墙柱边界、轴网定位及不同阶段的支承表达见 [墙、柱与轴网的关系](wall-column-grid-relationships.md)，其中单独标明已核对的正文依据。

## 依据与条文定位

[GB/T 50001—2017《房屋建筑制图统一标准》](https://www.gongbiaoku.com/book/6id19977k7u) 的发布公告为第1695号，实施日期为 2018-05-01；[GB/T 50104—2010《建筑制图标准》](https://www.gongbiaoku.com/mobile/book/nzg18501zaz) 的发布公告为第747号，实施日期为 2011-03-01。上述出版平台提供公告和目录，具体表达要求以适用的完整正文为依据。

2026-10-22 核对范围为公告与目录，以下仅供定位相关章节，不声称已经复核全部条文或数值要求。标准适用性与项目技术依据见 [规范查询](standards.md)。

| 内容 | GB/T 50001—2017 章节 |
|---|---|
| 图线、字体及比例 | 第4、5、6章 |
| 剖切、索引、引出及其他符号 | 第7章 |
| 定位轴线 | 第8章 |
| 材料图例与图样画法 | 第9、10章 |
| 尺寸线、数字及排列 | 第11.1—11.3节 |
| 标高 | 第11.8节 |

GB/T 50104—2010 的目录另列图线与比例、图例、图样画法和尺寸标注。章节定位不指定某个任务必须包含哪些图种，也不将随库符号视为所有标准图样的完整实现。

## 图纸用途、比例与表达深度

表达深度取决于图纸需要让读者理解的内容。空间分析可以突出边界与联系，构件定位需要可追溯的位置和尺寸，构造表达还涉及层次与连接；这些是信息用途的区别，不是所有任务都要依次制作的阶段。

简化符号可以省略细部，但要看被省略的信息是否影响当前理解。单线本身不等于错误，增加线数也不等于完整：作为技术平面中的墙体、洞口或设备表达时，厚度、交接及入口若关系到本图用途，就需要由图形或相关资料说清楚。仅调整线宽、字体和图框，无法补出原本缺失的几何与关系；已有房名或构件编号也不能代替这些内容。

比例决定细部在纸面上的可辨性。缩小后框扇、材料层次或相邻轮廓可能重合，放大后也可能显露缺失的构造。可以依据图种和适用约定取舍细节、补充局部表达或关联说明，而不是通过加粗、任意拉开构件或缩放符号掩盖问题。实际阅读效果结合 [视觉判断](viewing-editing.md)理解。

概念设定、原图事实和已核定构造有不同依据，表达精细程度不能把前者变成后者。方案中的支承与构件信息也不必全部推迟到施工图；对应设计深度文件的已核对范围见 [墙柱知识](wall-column-grid-relationships.md#资料状态与表达深度)。

需要理解具体线条含义时，按问题查阅 [门窗表达](door-window-representation.md)、[楼梯与电梯表达](stairs-and-lifts-representation.md)、[剖切与投影](sections-and-projections.md)或 [总平面的空间关系与表达](site-plan-representation.md)。这些关系说明不扩展上文对标准正文的核对范围。

## 当前助手的默认值与可调整项

下表描述 [china-conventions.yml](../assets/drafting/china-conventions.yml) 和 [Drawing](../src/ezarch/drafting.py) 的实际实现，不是标准条文摘录。尺寸均为纸面 mm；`style` 可覆盖这些配置，`pens_mm` 按图层合并。参数默认值不决定项目设计。

| 配置 | 当前默认值 | 作用 |
|---|---|---|
| `pens_mm` | 按图层配置，详见样式文件 | 纸面笔宽和 DXF 图层线宽 |
| `axis_circle_diameter_mm` | 8 | 轴号圆直径 |
| `index_circle_diameter_mm` | 10 | 默认索引圆直径；`index` 还可单独传入半径 |
| `north_circle_diameter_mm` | 24 | 随库指北针的整体比例 |
| `section_position_length_mm` | 7 | 剖切位置线长度 |
| `section_direction_length_mm` | 5 | 剖切方向线长度 |
| `excluded_axis_labels` | I、O、Z | 当前样式排除的轴号，可按采用的规则覆盖 |

字体可由 `font` 选择，实际字形、后备与输出文字形式见 [字体与排版](typography.md)；随库字体的来源与许可见 [字体授权](../THIRD_PARTY_NOTICES.md)。

## 独立绘图接口

下表对应随库绘图方法与所表达的信息；创建文档、绑定既有布局、单位和保存方式统一见 [Drawing 接口](geometry-drawings.md)。

| 现有方法 | 支持范围与参数含义 |
|---|---|
| `poly / line / rect / circle` | 二维几何；`poly(..., holes=...)` 支持直边孔洞，颜色、纸面线宽及虚线参数见 [图纸接口](geometry-drawings.md)；曲线填充可用原生 HATCH |
| `text` | 文字、纸面字高、对齐与旋转；实际字形及占位受所用字体影响 |
| `axis` | 既有方法为固定 x 或固定 y 的正交轴；独立 `grids.draw_axis/draw_axis_tag` 支持任意方向与显式轴号位置，见 [轴网与柱资源](grids-columns.md)。原生图元也可直接使用 |
| `dimension / chain` | dimension 支持端点对齐、斜向和指定方向投影，DXF 使用原生 DIMENSION；chain 为正交尺寸链 |
| `level` | 输入 `value_mm`，默认换算成 m 并保留三位小数；接近零显示 ±0.000，`label` 可指定显示文字 |
| `north / section_mark / index / leader` | 北针旋转、剖切位置与方向、索引号及图号、引线及文字；对应关系由调用者传入 |
| `symbol` | 放置 [可编辑组件](editable-components.md)；旧 furniture 方法只保留简化图形兼容行为 |

接口约定只作用于这次调用。`Drawing` 构造器新建文档；`Drawing.from_layout(...)` 可绑定已有模型空间、纸空间或图块，坐标采用目标单位，纸面尺寸、样式与保存约定见 [已有文档绑定](geometry-drawings.md#绘制到已有文档)。原生 ezdxf 的 ARC、块和 HATCH 能力可用于自定义表达；编辑既有实体见 [原生操作](edit-existing.md)。

## 图元、测量与输出的对应关系

符号所指的对象、方向、编号与基准决定其含义。剖切几何、可见投影、文字标注及材料填充分别承担不同表达，不能仅凭几何切片推断全部建筑符号。面积、净宽和标高的名称各有测量口径，使用时与实际对象及依据对应。

纸面字高、笔宽、符号尺寸和模型坐标之间由输出比例关联。旋转、视口变换、字体替换及缩放会影响阅读与标注位置；比例标签本身不改变实际尺寸。同一图元在不同后端的颜色、线型、字体及填充支持需按所选格式判断，文件可打开不代表各格式完全等价。

模型视图的可选 `drafting` 字段可调用这些绘图方法，参数仅约束该助手；独立 CAD、SVG 和其他表达可使用各自的数据与样式。制图表达、几何准确性与专业合规分别需要相应依据，技术工具不裁定审美与设计完成度。
