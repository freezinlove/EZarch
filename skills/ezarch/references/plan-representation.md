# 平面图的空间关系与表达

用于组织建筑平面及相关平面图的信息。表达详略取决于图纸用途与比例，构件画法可直接取用下方链接的专题知识。

## 楼层、边界与联系

建筑平面通常表达某一楼层的水平剖切与向下投影。墙柱、洞口及上下方投影的出现与剖切位置有关；局部裁图、标准层图所代表的范围也需清楚。高度关系见 [剖切与投影](sections-and-projections.md)。

墙柱轮廓表达实体占用，房间边界表达空间范围，房名只说明用途。门洞、门的开启、室内外高差和公共交通空间共同说明空间怎样连接，不能仅凭相邻或标签认为可以通行。截取单元或局部时，入口和连接空间可能来自另一图层或图块；裁图范围需要保留能解释本图的关联，或明确连接去向。

## 图纸用途与信息取舍

| 用途 | 重点承载的信息 |
|---|---|
| 建筑平面 | 本层空间、墙柱和开口之间的关系，以及与用途相符的定位和标注 |
| 家具布置 | 家具朝向、组合与使用空间；墙、门和通道提供位置与使用背景 |
| 屋顶平面 | 屋顶自身的边界、高差、坡向和排水关系，不能由楼层墙线直接替代 |
| 吊顶平面 | 顶面的分区、标高及相关设施位置，并与下方空间的定位关系对应 |

这些用途可以组合，所列也不是图种全集。保留哪些背景信息，取决于它是否帮助理解当前内容；同一底图可以复用，但不能只换标题就认为已表达另一对象。功能分区的概括性边界另见 [分析图知识](analysis-representation.md)。

## 定位与图面阅读

轴线、尺寸、房名、标高和引线各自说明位置、尺度或用途。重复线、密集家具和大面积填充可能掩盖墙厚、门洞与入口；简化表达仍需让这些与本图有关的关系可辨。标注占位可调整，实体之间的距离不能为排版随意拉开。

同一部位在平面、立面和剖面中可以有不同详略，但楼层、轴线、开口和高差应指向同一设计状态。旋转局部视图后，北向及定位标记随真实方向对应；图名中的比例与实际输出比例对应。取图与观察方法见 [视觉判断](viewing-editing.md)。
